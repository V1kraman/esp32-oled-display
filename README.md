# esp32-oled-display
A hands-on ESP32-S3 project that converts an MP4 video into 1-bit 128×64 frame data and plays it back on an SH1106 OLED. The project explored video-to-binary conversion, frame packing, I²C communication, OLED rendering, memory constraints, and timing optimization, while troubleshooting real hardware and firmware issues along the way.
